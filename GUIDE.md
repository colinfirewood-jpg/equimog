# EquiMoG : mode d'emploi

## À faire une seule fois (environ 15 minutes)

**Sur l'iPhone**

1. Ouvrir le lien de l'app dans **Safari** (pas un autre navigateur).
2. Toucher **Partager** (le carré avec la flèche), puis **Sur l'écran d'accueil**, puis **Ajouter**.
3. Toujours ouvrir EquiMoG avec cette icône. Les bilans sont rangés dans l'app de l'icône, pas dans Safari.
4. Dans l'app, toucher la roue dentée et écrire votre nom (il apparaît sur les PDF).
5. Dans l'app **Fichiers**, aller dans **iCloud Drive** et créer un dossier **EquiMoG**.

**Sur le PC Windows**

1. Installer **iCloud pour Windows** depuis le Microsoft Store (gratuit).
2. Se connecter avec son identifiant Apple et cocher **iCloud Drive**.
3. Le dossier **iCloud Drive › EquiMoG** apparaît dans l'Explorateur de fichiers.

## Au quotidien

1. **Nouveau bilan** : choisir *Début de cycle* (nouveau patient) ou *Fin de cycle* (patient déjà vu).
2. Un tap par item. Bleu = point acquis, brique = déficient. Le score se calcule tout seul.
3. **Terminer**, puis **Générer le PDF**.
4. Dans le menu qui s'ouvre : **Enregistrer dans Fichiers › iCloud Drive › EquiMoG**. L'iPhone retient ce dossier pour les fois suivantes.
5. Sur le PC : dans Vega, ajouter le document au dossier patient en le prenant dans **iCloud Drive › EquiMoG**.

Pour le bilan de fin, l'accueil affiche **Faire le bilan de fin** sous le patient : tout est déjà rempli.

## Bon à savoir

- **Les bilans restent uniquement sur l'iPhone.** Rien n'est envoyé sur Internet.
- **Sauvegarde** : une fois par mois, roue dentée › **Faire une sauvegarde** › Enregistrer dans Fichiers › iCloud Drive. En cas de nouveau téléphone : roue dentée › **Restaurer une sauvegarde**.
- **Supprimer un patient** : glisser sa carte vers la gauche.
- **Refaire un PDF** : bouton **PDF** à côté du bilan, sur l'accueil.
- Une fois les PDF importés dans Vega, vous pouvez les effacer du dossier iCloud.
